# 2DAM-PMDM-Recursos

Ejemplos, laboratorios, proyectos iniciales y recursos de Programación Multimedia y Dispositivos Móviles para **2.º DAM semipresencial · curso 2026/27**. Complemento de AULES.

## Empieza aquí

1. Abre la unidad que te indique el docente y lee su guía de trabajo.
2. Descarga una copia desde **Code → Download ZIP** o clona el repositorio.
3. Sigue el README del proyecto inicial y conserva la estructura de carpetas.
4. Estudia, practica y registra tus resultados. Entrega en la tarea indicada en AULES.

```bash
git clone https://github.com/JaumeLloret/2DAM-PMDM-Recursos.git
```

## GitHub y AULES

Aquí puedes leer y descargar materiales de estudio, ejemplos y proyectos iniciales. En el curso institucional de AULES encontrarás la ruta de cada semana, los cuestionarios, las fechas vigentes, las entregas y el feedback. La recuperación se asigna desde AULES. Si un material conserva una fecha orientativa, comprueba el calendario del curso antes de organizar una entrega.

Los ejemplos usan datos ficticios `DEMO-*`. Trabaja en una copia y conserva registro de versión y resultado. No uses datos personales ni credenciales reales en pruebas o capturas. Los tests y las simulaciones acreditan únicamente lo que ejecutan; las comprobaciones de hardware se coordinan con el docente.

La biblioteca de [Proyecto Intermodular II](https://github.com/JaumeLloret/2DAM-PI2-Recursos) reúne las guías y plantillas de coordinación de AulaFlow 2.0.

Consulta las licencias y condiciones de cada herramienta y dependencia en sus fuentes oficiales. Esta publicación no añade una licencia nueva a materiales de terceros.
