# Balizas del muelle · starter público

Godot 4.7.2 estándar/GDScript, Compatibility. Importa project.godot y ejecuta la escena principal. Pulsa Iniciar; usa WASD/flechas o cruceta táctil; P/Escape o botón para pausa, y Silenciar para audio. Reiniciar restablece ronda. Sin cuentas, datos personales ni servicios externos.

Objetivo: recoger tres esferas y volver al muelle en 60 s, evitando conos; tres vidas.

El starter es una base ejecutable: aún faltan reglas TODO y audio de hit/win/lose. Solo incluye CellA; crea instancias CellB y CellC con identidad/posición propias, completa recogida/daño/victoria y recursos solicitados por el laboratorio. Un arranque correcto no es aceptación del juego completo.

Los tests docentes se mantienen fuera del proyecto público. Sigue la guía de práctica para crear tus verificaciones y registrar QA. Un APK compilado no demuestra instalación física; no distribuir claves ni seriales. Exportación Android de entrenamiento con templates 4.7.2, conforme al entorno documentado en la unidad.
