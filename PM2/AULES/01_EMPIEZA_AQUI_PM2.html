PM2 · Empieza aquí

Aprenderás a convertir datos débiles y reglas dispersas en clases Dart pequeñas que puedas ejecutar, comprobar y justificar. Dispones de 8 horas, 480 minutos.

Necesitas el entorno Dart de PM1 y tu editor: VS Code con Dart o Android Studio con Dart/Flutter. Abre la carpeta del proyecto que contiene pubspec.yaml.

Tus tres primeras acciones

  1. Comprueba en una terminal dart --version. Debe mostrar una versión.
  2. Descarga los ejemplos Dart, descomprime el ZIP y abre la carpeta del proyecto.
  3. Ejecuta dart pub get y después dart run bin/main.dart. La primera línea será null-safety: SIN RESPONSABLE.

Después realiza el diagnóstico inicial y continúa por la Ruta de aprendizaje, con los ocho pasos, tiempos y checkpoints.

Entregarás el proyecto Dart del laboratorio, DECISIONES.md, EVIDENCIA.md y una evidencia breve de tu microvariación en Entrega · AulaFlow Dart Domain Lab.
