# AulaFlow Dart Domain Lab · starter

Proyecto didáctico local. No contiene widgets, API, persistencia ni modelo contractual de AulaFlow 2.0.

```bash
dart pub get
dart run bin/main.dart
dart test
```

El código inicial ejecuta, pero concentra datos en maps/strings, admite nulos débiles y expone colecciones. Lee [Unidad/05_LABORATORIO_PM2.md](../../../Unidad/05_LABORATORIO_PM2.md); crea tu propia estructura y documenta decisiones. No edites para que «se parezca» a una solución filtrada: cada clase debe responder al problema.

Salida inicial esperada:

```text
ANTES · todo=2 · doing=0
MOVE · C-1 movida
DESPUÉS · todo=1 · doing=1
SNAPSHOT · board-demo|todo:1|doing:1
```
