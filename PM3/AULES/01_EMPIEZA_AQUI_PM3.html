PM3 · Empieza aquí

Vas a construir una interfaz Flutter local que se adapta al espacio, navega por destinos y detalle, y mantiene el estado fuera de los widgets cuando pertenece a toda la feature. Dispones de 720 minutos; todo el trabajo obligatorio está incluido.

Tu primer resultado

  1. Abre la carpeta del starter que contiene pubspec.yaml.
  2. Ejecuta flutter pub get, flutter analyze, flutter test y flutter run.
  3. Comprueba que ves tres destinos y tareas DEMO-*.

Si no ocurre, no reinstales todo: abre Ayuda PM3 y conserva el comando y el primer mensaje de error.

Herramientas

VS Code con Flutter/Dart es el editor recomendado; Android Studio también es válido y proporciona SDK Manager y Device Manager. Android Studio puede gestionar el SDK/AVD aunque edites con VS Code.

flutter --version
dart --version
flutter doctor -v
flutter devices

Cómo comprobar el layout

Con Chrome puedes usar la barra de dispositivos de las herramientas de desarrollo y escribir 390 × 800 y 900 × 700. En Android aumenta la fuente desde Ajustes → Accesibilidad → Tamaño de visualización y texto. Los anchos son píxeles lógicos.
