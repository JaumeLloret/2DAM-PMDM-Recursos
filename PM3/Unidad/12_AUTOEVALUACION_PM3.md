# PM3 · ¿Estoy realmente listo para entregar?

> Fuente anterior conservada para trazabilidad. La publicación vigente se define en el manifiesto AULES v3 y usa los libros integrados 13–16; este documento no se exporta como una actividad separada.


Esta parada es formativa. No sustituye I2 ni I3.

## Puedo explicarlo y hacerlo

- [ ] Explico la diferencia entre widget, elemento y estado sin afirmar que cada rebuild redibuja todo.
- [ ] Diagnostico un overflow desde padre, constraint e hijo.
- [ ] Justifico un breakpoint por espacio y contenido.
- [ ] Distingo estado local de estado de feature.
- [ ] Navego por id y manejo un id inexistente.
- [ ] Puedo narrar control → callback → comando → estado → rebuild.
- [ ] El ViewModel recibe un repositorio; no crea su fuente.
- [ ] Sé por qué no añadí un Service vacío.
- [ ] Distingo lista vacía de fallo de carga.
- [ ] Puedo reparar un fallo con hipótesis, cambio mínimo y regresión.

## Comprueba la app

- [ ] `flutter pub get`, `flutter analyze` y `flutter test` reflejan el estado real.
- [ ] La app ejecuta y los cuatro destinos previstos son recorribles.
- [ ] A 390 px hay bar y no hay overflow.
- [ ] A 900 px hay rail y el cuerpo ocupa el espacio restante.
- [ ] El texto ampliado no oculta acciones esenciales.
- [ ] Teclado/foco y etiquetas se comprobaron cuando el destino lo permite.
- [ ] Cancelar no cambia; confirmar cambia una vez y muestra feedback.
- [ ] Vacío, loading y error tienen respuestas diferentes.

## Comprueba la entrega

- [ ] Incluyo proyecto, decisiones, checklist, registro y evidencias pedidas.
- [ ] No incluyo `build/`, secretos, datos reales, `.env` ni solución docente.
- [ ] Declaro las ayudas/IA utilizadas y cómo verifiqué el resultado.
- [ ] La evidencia I3 contiene predicción previa, cambio, ejecución y explicación sin agente.
- [ ] El ZIP o carpeta se abre y contiene `pubspec.yaml`, `lib/` y `test/`.
