# motor_lab · proyecto base público

Godot 4.7.2 estándar, GDScript, renderer Compatibility. Importa project.godot y ejecuta el proyecto. Botones accesibles por foco/teclado o puntero: iniciar/detener giro, cambiar escena y restablecer. Es un laboratorio de análisis de un proyecto existente, no un juego completo ni una evidencia de hardware.

Conserva una copia inicial antes de experimentar. No alteres más de una variable a la vez.

Los modelos, polígonos, materiales y código son originales de esta campaña; no se descargan assets. No hay datos reales, cuentas ni servicios. La licencia del motor debe acompañar una distribución de binarios; consulta LICENSES.md. Android se analiza como destino en PM8; el juego móvil completo y su exportación corresponden a PM9.

Incluye un minijuego ya terminado para identificar bloques funcionales (RA4.e): secuencia A-B-A en 10 s, error o timeout termina la ronda, reinicio disponible. Se analiza su arquitectura; no se pide desarrollarlo en PM8. El tono no es la única señal: texto, estado y contador permiten jugar sin sonido.
