# spec_search · starter público

Flutter 3.47.2, Dart 3.13.2. Proyecto local, datos DEMO, sin servicio ni persistencia. Ejecuta `flutter pub get`, `flutter analyze --fatal-infos` y `flutter test`. El starter funciona como catálogo de partida y aún no implementa la feature. Su smoke test no es la aceptación de la feature.

Para Android sigue el entorno PM7: genera plataforma temporal con `flutter create --platforms=android --org org.aulaflow.training .`, conservando fuentes y tests de este material; retira solo el test de contador generado si aparece. `flutter build apk --debug` crea un artefacto de entrenamiento. No se infiere instalación física de un build.

Trabaja en una rama propia con proceso documentado. No incluyas soluciones docentes ni secretos en contexto de agente. El código y los datos son originales de la campaña; las dependencias conservan sus licencias.
